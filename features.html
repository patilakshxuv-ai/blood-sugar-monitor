Features

Features designed for simple personal records

A focused toolkit for entering, reviewing, and understanding the context around your own records.

Measurement log

Record values manually and keep dates and times associated with each entry.

Notes & context

Add context that may help you remember what was happening around an entry.

Local workflow

Use the tracker without relying on a cloud account for basic record keeping.

Readable history

Keep previous entries organized so you can review them before appointments.

Privacy-aware

The app's intended manual logging model keeps personal records on-device rather than sending them to a remote database.

Companion education

Use this website's guides to learn about record keeping and prepare better questions.
